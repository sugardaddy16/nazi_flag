## 中文說明

### 專案簡介

本專案使用 Python 的 `turtle` 模組，以程式化方式繪製納粹德國旗幟（1933–1945），作為圖形程式設計的練習範例。

### 檔案結構

| 檔案 | 說明 |
|------|------|
| `nazi.py` | 主要 Python 腳本，使用 `turtle` 繪圖 |
| `nazi.ipynb` | [Google Colab](https://colab.research.google.com/github/sugardaddy16/nazi_flag/blob/main/nazi.ipynb) 版本 |
| `LICENSE` | MIT 授權條款 |

### 環境需求

- Python 3.x
- `turtle` 模組（Python 標準函式庫，無需額外安裝）

### 使用方式

```bash
# 克隆此 repo
git clone https://github.com/sugardaddy16/nazi_flag.git
cd nazi_flag

# 執行腳本
python nazi.py
```

或者點擊 [`nazi.ipynb`](https://colab.research.google.com/github/sugardaddy16/nazi_flag/blob/main/nazi.ipynb) 以 Google Colab 開啟執行。

### 運作原理

腳本分三個步驟繪製旗幟：

1. **紅色矩形**：繪製 250×150 的紅色背景
2. **白色圓形**：在中央繪製半徑為 56.25 的白色圓
3. **黑色卍字符**：以旋轉 45° 的方式，用迴圈繪製出卍字圖案

## English

### About

This project uses Python's built-in `turtle` module to programmatically draw the flag of Nazi Germany (1933–1945) as a graphics programming exercise.

### File Structure

| File | Description |
|------|-------------|
| `nazi.py` | Main Python script using `turtle` graphics |
| `nazi.ipynb` | [Google Colab](https://colab.research.google.com/github/sugardaddy16/nazi_flag/blob/main/nazi.ipynb) version |
| `LICENSE` | MIT License |

### Requirements

- Python 3.x
- `turtle` module (part of Python standard library — no extra install needed)

### Usage

```bash
# Clone the repository
git clone https://github.com/sugardaddy16/nazi_flag.git
cd nazi_flag

# Run the script
python nazi.py
```

Or open [`nazi.ipynb`](https://colab.research.google.com/github/sugardaddy16/nazi_flag/blob/main/nazi.ipynb) in Google Colab.

### How It Works

The script draws the flag in three steps:

1. **Red rectangle**: Draws a 250×150 red background
2. **White circle**: Draws a white circle with radius 56.25 at the center
3. **Black swastika**: Uses a loop with a 45° rotation to render the swastika shape
